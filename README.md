## ✨ លក្ខណៈពិសេសចម្បង (Key Features)

- **យុទ្ធវិធីបង្រៀនជាក់ស្តែងសម្បូរបែប (Active Teaching Techniques)**: See-Think-Wonder, Claim-Support-Question, Think-Puzzle-Explore, Circle of Viewpoints, 3-2-1 Bridge, Chalk Talk, Compass Points, Jigsaw, Gallery Walk, Fish Bowl, World Café, Role Play, Case Study, Debate, Concept Mapping, etc.
- **Classroom Tools ក្នុងថ្នាក់រៀន**:
  - 🎡 **Picker Wheel / Random Student Wheel**: បង្វិលចាប់ឈ្មោះសិស្ស ឬបែងចែកក្រុមដោយចៃដន្យ
  - ⏱️ **Countdown Timer**: នាឡិការាប់ថយក្រោយលេខធំៗ ងាយស្រួលបញ្ចាំងស្លាយក្នុងថ្នាក់រៀន
- **Export សម្បូរបែប**: Word (.docx), PowerPoint (.pptx), Canva Bridge, PDF Print
- **មូលដ្ឋានទិន្នន័យវចនានុក្រម និងសៀវភៅពុម្ពក្រសួងអប់រំ**
- **ប្រព័ន្ធស្វែងរក និងធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិ (Auto-Update)** តាមរយៈ GitHub Releases
